# Tiles: terrain, cliffs, town, archive, interiors

Generated by `next/tools/art/tiles/` (deterministic Python, Pillow + numpy). Do not hand-edit the PNGs:
change the generator and rebuild. Everything is 16 px tiles, top-left light, colors from `../palette.json`.

| Sheet | Contents |
|---|---|
| `terrain.png` | ground autotiles (A2), animated water + ink (A1), fill variants, decal overlays |
| `cliffs.png` | cliff wall system (grass top + rock face), stairs cut into cliffs, one-way ledges |
| `town.png` | 11 prefab buildings (top) + modular kit: roofs, walls, doors, windows, awnings, fences, bridges, well, stalls, signs, banners, stairs |
| `archive.png` | Rootbound Archive: per-floor kits for F1 / F2 / F3 (see *Per-floor Archive kits* below); wall systems `archive` (stone cap around a flat `#14101e` void, two-tone face) and `archive_roots` (same cap and face over the old root-choked earth fill), archive floor, pillar, shelves (incl. moving shelf), tables, candelabra, braziers, roots, plates, switches, crystal switch, push block, doors (key, locked, boss), cracked wall, stairs, hidden-ink pieces, lantern pedestal |
| `interior.png` | 3 interior wall systems, wall windows, counter, beds, tables, chairs, hearth, goods shelves, barrels/pots/crates/sacks, rug, stairs |
| `tiles.json` | every id below with its rect, collision and autotile/anim data |

## tiles.json

```
{ version, tileSize: 16, collisionCodes: {...}, terrainOrder: [...],
  terrains: { id: {sheet, x, y, w:32, h:48, autotile:'A2'|'A1', kind:'fill'|'hole', collision, order,
                   variants:[[x,y],...], variantWeights:[...], anim?:{frames:[0,1,2,1], frameDx:32, ms}} },
  walls:    { id: {sheet, top:[x,y] (A2 block), face:[x,y] (32x32 face block), collision:'solid',
                   topVariants?, topVariantWeights?} },
  tiles:    { id: {sheet, x, y, w, h, collision, autotile?:'line16'} },
  objects:  { id: {sheet, rect:[x,y,w,h], anchor:[tx,ty], footprint:[[dx,dy],...], overheadRows,
                   doorAt:[dx,dy]|null, collision, kind:'building'|'prop'|'door'|'piece', anim?, note?} },
  overlays: { id: {sheet, x, y, w:16, h:16, collision:'none'} }   (also listed under tiles) }
```

### Collision codes
`none` walkable. `solid` blocks. `water` blocks walking (deep water, ink). `ledge_s` / `ledge_e` / `ledge_w`
walkable, but may only be entered moving south / east / west (hop down). `pit` stepping in drops the actor
to the floor below (the map supplies the target); AI never enters. `counter` blocks, but talk/interact reaches
across it (shopkeepers stand behind counters).

A terrain cell's collision is the terrain's code. A wall-system cell (top or face) is `solid`. Object
footprints are `solid` except the `doorAt` cell. Tiles carry their own code (stairs, bridge decks: `none`;
bridge piles/arches: `water`, i.e. the water below stays unwalkable).

## Terrain autotiles (A2) and layering

Each terrain is an RPG Maker VX/MV "A2" block: 32 x 48 = 2 x 3 tiles = 4 x 6 quarters (8 px).

```
qy0  [iso TL][iso TR][inner TL][inner TR]     tile (0,0): isolated cell   tile (1,0): inner corners
qy1  [iso BL][iso BR][inner BL][inner BR]
qy2  [outer TL][top ][top  ][outer TR]        bottom 2 x 2 tiles: outer corners, edges, centre
qy3  [left   ][cent][cent ][right   ]
qy4  [left   ][cent][cent ][right   ]
qy5  [outer BL][bot ][bot  ][outer BR]
```

A cell is drawn as four quarters. For quarter TL use v = N connected, h = W connected, d = NW connected:
`!v&&!h` outer (0,2); `!v` top (2,2); `!h` left (0,4); `!d` inner (2,0); else centre (2,4).
TR (N, E, NE): outer (3,2) top (1,2) right (3,4) inner (3,0) centre (1,4).
BL (S, W, SW): outer (0,5) bottom (2,5) left (0,3) inner (2,1) centre (2,3).
BR (S, E, SE): outer (3,5) bottom (1,5) right (3,3) inner (3,1) centre (1,3).
This is identical to MV's FLOOR_AUTOTILE_TABLE. Off-map neighbours count as connected.

**Layering.** `terrainOrder` lists terrains low to high. A terrain's edge lies inside its own cells and is
transparent outside the boundary. To draw cell (x, y) whose terrain is T:
1. collect the terrains present in its 3 x 3 neighbourhood with order <= order(T), sorted low to high;
2. the lowest one is drawn as a full fill (a variant tile, see below);
3. each higher one L is drawn as an A2 cell where neighbour n is connected iff order(n) >= order(L).

Holes (`water`, `shallow`, `ink`, `pit`) are highest, so they draw their own banks and lips; grass draws its
tufted edge over dirt and sand; the plaza draws a dressed curb over grass. A `pit` has a light rim all round, an irregular
outline and its far wall as a cut stone face fading to ink, so it reads as a hole (W8, see *Per-floor Archive kits*). `ink` (W5-art, CRITIQUE_2 item 5) is a dark violet-indigo liquid, not flat navy:
an ink:2 body with soft ink:1 depth bands, slow highlight ripples (thin ink:3 arcs that drift and breathe over the
3 A1 frames) with ink:4 glints, a lighter meniscus ring (ink:3, shimmering to ink:4) inside the shore, a light stone
rim all round (W8) and a cut stone face under the far bank. Preview: `python compose.py ink_test`
(`out/preview_ink_test.png`; set the scene's `frame` to 1 or 2 for the other frames). `plaza` keeps its mortar in the mid step and dresses only every third stone,
so actors out-contrast the floor (6 fill variants). `carpet_red` / `carpet_blue` read as cloth: a dark hem with
a fringe stitch on the N and S ends, a gold line, a knot stripe and a soft woven field. Pre-render each map layer once
into an offscreen canvas per animation frame; the cost is a few quarter blits per cell.

**Fill variants.** When all 8 neighbours of a layer are connected, draw `variants[k]` instead of the A2
centre, with k picked by `pickVariant(x, y, variantWeights)` (hash below). Variants only change the inside of
the tile, so any variant sits next to any other or next to an edge piece without a seam.

**A1 animation** (`water`, `ink`): frame f of the block is at `x + anim.frames[i] * anim.frameDx`; advance i
every `anim.ms`. All three frames share the same edge geometry.

## Wall systems (3/4 view)

`cliff`, `archive`, `archive_roots`, `interior`, `interior_wood`, `interior_stone`. Maps mark top cells `<id>_top` and face
cells `<id>_face`. `archive_top` fills with flat `#14101e` inside its stone cap (beyond the walls is black);
`archive_roots_top` is the old hatched earth fill for maps that want a visible earth mass (it shares the archive
face block). The archive face is two-tone: the course under the cap is lit, the course on the floor is one ramp
step darker and ends in a dark plinth with a shadow line (CRITIQUE_1 C6). Faces sit directly below the south edge of a top region and are usually 2 rows tall (cliff
1 to 3). The top is an A2 block (connected = same `<id>_top`; face cells are *not* connected, so the top
draws its south lip). The face is a 32 x 32 block composed by 4-neighbour connectivity (same `<id>_face`):

```
TL: (left ? 2 : 0, top ? 2 : 0)      TR: (right ? 1 : 3, top ? 2 : 0)
BL: (left ? 2 : 0, bottom ? 1 : 3)   BR: (right ? 1 : 3, bottom ? 1 : 3)      (quarter coords, 8 px)
```
(identical to MV WALL_AUTOTILE_TABLE). Tiles such as `wall_shelf_*`, `wall_cracked`, `wall_glyph_*`,
`window_in*` and objects such as `door_*`, `stairs_up`, `hearth` are drawn over face cells.
`cliff` also has `topVariants` (grass fill variants) used like terrain variants.

## line16 autotiles

`fence_wood`, `wall_low`, `fence_iron`, `counter`: 16 tiles in a row of 8 x 2. Index = N*1 + E*2 + S*4 + W*8
(bit set when that neighbour carries the same id); tile i at `(x + (i % 8) * 16, y + floor(i / 8) * 16)`.

## Objects (prefabs and props)

Place an object on map tile (X, Y): its `anchor` tile [tx, ty] (tile coords inside `rect`) lands on (X, Y),
so the rect's top-left pixel is `((X - tx) * 16, (Y - ty) * 16)`. Anchors are the bottom-left footprint tile.
`footprint` cells are relative to the anchor (dy <= 0 goes up). `doorAt` (relative to the anchor) is the
walkable door cell: put the map's door event there. Draw rows `[overheadRows, rows)` of the rect in the
object layer under actors and the top `overheadRows` rows above actors; footprints are sized so that this
split is exact (every non-overhead row is solid, so no actor can stand where a base row is drawn; for props
the build derives `overheadRows = rows - footprint depth`). If the renderer y-sorts objects with actors
instead, sort by the anchor row and ignore `overheadRows`. Buildings have one extra transparent column
on the right that carries the cast shadow; it is never in the footprint. `anim` works like A1:
frame k at `rect.x + frames[i] * frameDx`.

Buildings: `house_small house_medium house_large hero_home inn item_shop smithy bakery library
chapel_bell_tower town_gate`. Town props: `well signpost signpost_arrow market_stall_fruit market_stall_cloth
gable_<red|blue|purple|green>`. Archive: `shelf_a shelf_b shelf_wide shelf_moving reading_table
reading_table_long root_column pillar candelabra brazier_lit brazier_unlit crystal_switch_blue crystal_switch_gold
lantern_pedestal lantern_pedestal_empty push_block door_key_* door_locked_* door_boss_* (closed|open)
stairs_up stairs_down`. `pillar` is a 16 x 32 free-standing column (footprint 1 tile, capital row overhead) for
room corners and alcoves. Interior: `bed_single bed_single_red bed_double table_round table_long shelf_potions
shelf_bread rack_weapons rug_round stairs_in_up stairs_in_down hearth`.

Door objects (`door_*`, `stairs_*`) are set into a 2-row wall face: anchor = bottom-left doorway cell.
Closed doors list the doorway as footprint; open ones list it as `doorAt`.

## Per-floor Archive kits (W8-archive, CRITIQUE_3 items 3 and 4)

Each Archive floor has its own floor terrain, wall band, inner face, the deep beyond its walls, an outer face,
props and one landmark. Generators: `archive_floors.py` (terrains and wall systems) and `archive_props_w8.py`
(props), both appended to `archive.png` by `archive.py`. The old `archive` / `archive_roots` systems and
`archive_floor` are unchanged (the test maps still use them).

| Floor | Floor terrain | Walls (`<sys>` and `<sys>_out`) | Props | Landmark |
|---|---|---|---|---|
| F1 Catalog Halls | `catalog_wood` warm oak parquet, basket weave, dropped index cards | `catalog`: walnut cap, brass front lip, oak panels over card drawers; `catalog_out`: shelf and drawer silhouettes in the dark, oak siding falling away | `card_cabinet` (32x32 object), `pillar_oak`, `book_stack` (1-tile object), `index_cards` (decal), `wall_drawers_<l\|m\|r>` (16x32 face overlays) | `great_catalog_dial` (32x32 face overlay: the brass index wheel in the drawer wall) |
| F2 Reading Galleries | `gallery_stone` cold slate harlequin, glass inlays | `gallery`: slate cap, verdigris lip, slate ashlar under a verdigris frieze; `gallery_out`: dark leaded lancets in the dark | `lectern` (object), `gallery_window` (16x32 face overlay), `hanging_lamp` (16x32 tile for the map `overhead` list; pair it with a `light` event) | `gallery_rose` (48x32 face overlay: the rose window) |
| F3 Rootbound Stacks | `stacks_wood` dark long floorboards, roots, ink in the seams | `stacks`: root-choked cap with ragged edges, dark panelling with roots and ink; `stacks_out`: root fragments in the black, a curtain of roots falling away | `shelf_rooted` (32x48 object), `root_mass_a` (32x16) / `root_mass_b` (16x32) braids for wall tops, `root_drape` and `wall_ink_seep` (16x32 face overlays) | `root_arch` (80x32 tile for the map `overhead` list, at (door x - 1, door top row): roots knotted over the great door) |

Footstep surfaces follow the ids (`*_wood` = wood, `gallery_stone` = stone).

**Wall depth.** The maps keep carving rooms out of `#`, then classify the wall cells (`depth()` in each
`src/data/maps/archive_*.js`): a wall cell touching a room (8-neighbourhood) stays the band `#` = `<sys>_top`, a full
tile of wall top, so walls have thickness; a wall cell under the band's south side becomes the outer face `o` =
`<sys>_out_face` (one or two rows); every other wall cell is the deep `v` = `<sys>_out_top`. All of them are `solid`.
The band's A2 edges are directional (bright front lip on S, dark back edge on N, lit W, shaded E) whatever the
neighbour is, so the same piece serves a north wall (face below), a south wall (outer face below) and a side wall.
`<sys>_out_top` has no edges at all (every quarter is the fill), so the deep is seamless; both tops carry
`topVariants`. Face blocks are cut per quarter, so `FaceStyle` rows 0..7 only see `top` and rows 8..15 only see
`bottom`: the per-floor faces are written as a head (8 rows), a 16-periodic body and a foot (8 rows)
(`archive_floors.SplitFace`).

Overlays on wall cells must be solid (an overlay's collision replaces the cell's); the root masses are placed through
`rootMasses()` in the maps, which drops any placement that would touch a floor or face cell. `hanging_lamp` and
`root_arch` are collision `none` and belong in `overhead` only, never in `overlays`.

**Ink and pits (CRITIQUE_3 #4).** `ink` and `pit` have an irregular outline (a bigger wobble plus a few bites), a
light rim all round (stone_cool 5 on the far lip, 4 on the west, 3 on the near and east lips), the far bank as a cut
face going down in courses, and a darker band on the ink under the far bank. `ink_bridge_<h|v>_revealed` carries a
faint, dithered pale cyan glow on the ink either side of the deck (the Lantern's light caught under the planks). The
maps also break the pool and pit outlines into ragged cell shapes where no prop or crossing depends on them.

Previews: `python w8_swatch.py <terrain or wall top ids>` (out/w8/swatch.png, 3x) and `python w8_props_sheet.py`
(out/w8/props.png); whole floors with `python ../../maps/preview.py archive_f1 --crop=0,0,40,30 --scale=2`.

## Reference code and hash

`next/tools/art/tiles/autotile_ref.mjs` holds the runtime rules as pure ES functions (`quarterSrc`,
`a2Quarters`, `faceQuarters`, `line16Index`, `variantHash`, `pickVariant`, `terrainLayers`).
`python verify_ref.py` checks them against the generator (node + python must agree on 700+ cases).

```js
export function variantHash(x, y, salt = 0) {
  let h = (Math.imul(x, 73856093) ^ Math.imul(y, 19349663) ^ Math.imul(salt, 83492791)) >>> 0;
  h = (h ^ (h >>> 13)) >>> 0;  h = Math.imul(h, 1274126177) >>> 0;  return (h ^ (h >>> 16)) >>> 0;
}
```

## Regenerate and preview

```bash
cd next/tools/art/tiles
python palette_build.py          # assets/palette.json + palette.png (run first; tiles read it)
python build_tiles.py            # all sheets + tiles.json (or: python build_tiles.py town archive)
python check_palette.py          # every opaque pixel must be a palette color (exit 1 otherwise)
python verify_ref.py             # JS reference == generator
python compose.py                # previews of every scene in scenes.py -> out/preview_<name>.png (3x)
python compose.py my_scene.json  # any ASCII scene (legend + ground + decor, DESIGN 5.1 style)
python stress.py                 # autotile seam stress test -> out/stress_*.png
```

Deliverable previews (3x): `out/preview_riverside.png`, `out/preview_lantern_square.png`,
`out/preview_archive_room.png`, `out/preview_house_interior.png`. QA scenes: `archive_room2`, `valley`,
`town_overview`, `kit_town`, `interior_test`, `cliff_test`, `cliff_test2`, `terrain_test`, `dungeon_test`.

Scenes may reference ids from `assets/sprites/props.json` (trees, lamp posts, benches); the composer draws
them read-only so previews show real context. Translucent pixels in the sheets are cast shadows
(indigo `#14101e` at about 42%) meant to be composited by the renderer.
