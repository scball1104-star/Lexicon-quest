# Backdrops (384 x 216, palette-quantized key art)

Generated by `next/tools/art/backdrops/build.py` from `../assets/art/environments.webp` (2 x 4 cells). Do not
hand-edit: change the recipe in `build.py` and rebuild (`python build.py`, about 20 s, deterministic).

Each backdrop is the painted cell box-downscaled to the internal resolution, lightly sharpened, graded, and
quantized to `assets/palette.json` with a Bayer 4 x 4 ordered dither between neighbouring palette colours,
plus up to four extra colours per backdrop where the palette cannot carry a hue (listed in the json as
`extraColors`). Every frame has under 80 colours, so the key art sits at the same pixel density as the tiles
and sprites (CRITIQUE_1 C1). Draw them with nearest-neighbour at (0, 0); never scale or smooth them.

**Stage band.** Battle backdrops are NOT banded in the png. The battle scene fills rows `bandY..216` with
`#14101e` at `bandAlpha` under the sprites (feet stand at y 148, the bottom windows cover y 152..212), so the
band can move with the layout. `bandY` 118 is the floor line the mocks were judged with
(`tools/art/backdrops/out/mock_battle_*_3x.png`).

**Manifest.** `qa/core/sync-manifest.mjs` scans `assets/ui`, `assets/sprites` and `assets/tiles` only, so these
files are loaded by path (`assets/backdrops/<id>.png`, `<id>.json`). Add `assets/backdrops` to its `SCAN_DIRS`
if they should become manifest images (`images.<id>`); the stems do not collide with any existing id.
