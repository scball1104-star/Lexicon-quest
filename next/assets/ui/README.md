# assets/ui: fonts, windows, cursor, icons, battle HUD, logo, emotes, touch skins

Everything here is generated by deterministic Python in `next/tools/art/ui/` (owner: W1-ui-art).
Regenerate all of it with:

```
python next/tools/art/ui/build_all.py         # ~0.5 s, rewrites every file in this folder
python next/tools/art/ui/mock_screens.py      # mock screens -> next/tools/art/ui/out/mock_*_3x.png
```

All colors come from `next/assets/palette.json` (read at build time), except: font glyphs (pure white, tinted
by code) and the five rarity colors fixed by DESIGN 6.4. `build_all.py` audits `ui.png` and prints any opaque
color outside the palette (currently 0, rarity beams excluded).

## Files

| File | What |
|---|---|
| `font.png/json` | Main proportional font. Cap height 7, x-height 5, descent 2, lineHeight 11, baseline 8, spaceAdvance 3. ASCII 33..126 plus `‘ ’ “ ” … ♥ ★ ♪ ← ↑ → ↓ × · • – − ✓ ▲ ▼ ● ○`. Digits are tabular (advance 6). |
| `font_large.png/json` | Title / banner / header serif. Cap height 11, x-height 7, descent 3, lineHeight 16, baseline 13, spaceAdvance 4. Full ASCII plus `‘ ’ “ ” … ×`. |
| `font_num.png/json` | Battle digits `0-9 + - % !` with a built-in ink outline, pre-colored. Also holds the word art. |
| `font_num_big.json` | Bigger crit digits (same PNG). |
| `window.png/json` | 9-slice window frames (`std`, `field`, `thin`), speech tails, 6 color schemes. |
| `logo.png/json` | Title logo (276x58), subtitle ribbon "The Reforged Realms" (204x24), 5-frame sparkle. |
| `ui.png/json` | Atlas of every other piece (256 frames): cursor, arrows, icons, battle HUD, emotes, prompts, banner, touch skins, button glyphs, rarity beams. |
| `touch/*.png` | The touch skins as separate files for the DOM overlay (`input.setTouchSkin`). |

## Fonts (format: COMMON.md)

`glyphs: {char: [x, y, w, h, xoff, yoff, advance]}`, `kerning: {"AV": -1}`. Keys are literal characters
(non-ASCII included). Glyphs are white on transparent: tint them, and draw the shadow in code (1 px down-right,
`#14101e`). Extra keys (`name, capHeight, xHeight, descent, shadow, monoDigits`) are informational.

Named colors for `{c:name}...{/c}` (also in `ui.json` `textColors` and `rarity`):

| name | hex | | name | hex |
|---|---|---|---|---|
| white | `#f6f4ee` | | red | `#e06b39` |
| gray | `#b3b6c4` | | orange | `#eba14d` |
| dim (disabled) | `#8e8997` | | violet | `#bc94e2` |
| gold | `#f9d77a` | | pink | `#fcc4dc` |
| cream | `#fff7d6` | | shadow | `#14101e` |
| cyan | `#8af0e8` | | common / magic / rare | `#e8e8e8` / `#6f8cff` / `#ffd34d` |
| blue | `#6ab3e4` | | legendary / set | `#ff8a2a` / `#3cdc6a` |
| green | `#b6cc58` | | | |

Disabled menu options: draw text in `dim` and icons at 50% alpha.

**font_num / font_num_big are NOT tintable.** Draw them untinted with no code shadow (`"shadow": false`).
Pick a color set by adding `variants[name]` to every glyph's `y`:
`font_num` variants `white` (damage), `crit`, `heal`, `mp`, `poison`, `gray`; `font_num_big` variants `white`, `crit`.
Glyph advance is width - 1, so neighbors share their outline column. DESIGN 6.5: normal hit = `font_num`
white, crit = `font_num_big` crit, heal = `heal`, MP = `mp`.
Word art is in `font_num.json` `words: {"MISS": [x, y, w, h]}` (MISS, CRITICAL, WEAK, BREAK, RESIST, IMMUNE,
GUARD, DODGE). Draw it as a sprite centered on the target.

## Windows (`window.json`)

`frames.std | field | thin = {rect, border, fillInset}`. Draw order for a window at `(x, y, w, h)`:

1. Fill `(x+i, y+i, w-2i, h-2i)` with `i = fillInset` using a vertical gradient, 1 px rows, no dithering:
   `colors[scheme].top` at the first row, `mid` at 45%, `bottom` at the last row (linear between).
   On the field use `alpha = fieldAlpha` (0.92) for the fill only.
2. `nineSlice(frame)` over it. Edges are uniform, so stretching equals tiling. The center is transparent.

Schemes (`colors`): `blue` (default, FF6-like), `crimson`, `forest`, `violet`, `slate`, `ember`. Each has
`top, mid, bottom, highlight` (tint for the selection bar) and `accent`.
`std` = 4 px frame (ink outline, 2 px light bevel, inner shadow line on top/left, rounded corners).
`thin` = 3 px frame for name tabs, tooltips, telegraph strips, portrait frames (portrait frame: thin window
`(x, y, 52, 52)`, portrait at `x+2, y+2`). `field` = `std` with a lighter shadow line.

**Speech tails** (`tails.tail_down | tail_up | tail_down_field | tail_up_field`): each has a frame and a
`_fill` mask. Position so the tip is at the speaker: sprite x = `tipScreenX - tipX`; `tail_down` sprite top =
window bottom - 4 (window above the speaker), `tail_up` sprite bottom = window top + 4. Draw the fill mask
tinted with the gradient color of the adjacent window edge (same alpha as the fill), then the tail frame.

## ui.json

`frames: {id: [x, y, w, h]}`, `origins: {id: [ox, oy]}` (draw at `x - ox, y - oy`; absent = top-left),
`anims: {id: {frames, fps, loop}}`, `slices: {id: {border: [l, t, r, b], ...}}`, `groups`, plus lookup maps
`icons.weakness`, `icons.status`, `icons.statusMini`, `icons.large16`, `buttonGlyphs.keyboard|gamepad|touch`.

### Menus and dialogue
- `cursor_0/1` (18x12 glove, anim `cursor` 4 fps): origin = fingertip hotspot. Put the hotspot 2 px left of
  the option's first pixel; frame 1 bobs 1 px toward the option.
- `sel_bar` (3-slice `[3,0,3,0]`, 12 tall): white + alpha; tint with `colors[scheme].highlight`, stretch to row width.
- `arrow_up/down` (9x6 scroll arrows), `arrow_left/right` (6x9 page arrows), `page_on/off` (5x5 page dots).
- `more_0..3` (anim `more`): "more text" arrow, bottom-right of the dialogue window. `end_0/1`: end-of-message mark.
- `delta_up/down/same` (5x6): equip stat deltas (green up, red down, equal).
- `banner_l/m/r` (24 tall): location banner. Left cap, `banner_m` stretched, right cap; `font_large` text in
  `cream` centered, text top = banner y + 2. Slide in on map entry for 2 s.

### Icons
- `icon_<id>` 12x12 (60 frames): sword spear staff axe bow shield armor helm charm boots mantle potion ether
  phoenix key letter gold star fire ice thunder light book lantern bag chest scroll magic gear quill quest flee
  swap combo. Status badges (12x12, colored tile + white symbol): poison burn chill stun silence blind regen
  protect haste focus fury taunt nameless.
- `st8_<status>` 8x8 mini badges for the battle HUD row.
- `icon16_<id>` 16x16: sword spear staff axe bow fire ice thunder light lantern book letter (loot pop-ups,
  key item fanfare, equip headers).

### Battle HUD
- Gauges: `gauge_frame` (6 tall, 3 px fill) and `gauge_frame_thin` (5 tall, 2 px fill), 3-slice `[2,0,2,0]`.
  Fill = 1 px wide slices repeated across `(x+1, y+1, round((w-2)*frac), fillHeight)`:
  `gauge_hp` (above 50%), `gauge_hp_mid` (25 to 50%), `gauge_hp_low` (25% and below), `gauge_mp`, `gauge_fury`,
  `gauge_exp`, `gauge_atb`, and `gauge_lag` (white damage trail, drawn first, shrinks after a delay).
  Add `_thin` for the thin frame.
- Fury full: tile `fury_shine_*` (24 px period, anim `fury_shine`) over the fill and draw `gauge_glow_*`
  (9-slice `[4,4,4,4]`, anim `gauge_glow`) at `(x-2, y-2, w+4, h+4)`. Tiny label `lbl_ready`.
- Timeline: `tl_party | tl_enemy | tl_current | tl_elite | tl_preview` (18x18; 14x14 transparent window at
  `+2,+2` for a 1:1 face crop, e.g. a 14x14 crop of the 32x32 portrait). `tl_glow_0/1` (22x22) behind the
  current slot at `-2,-2`. `tl_rail` 3-slice behind the row. `tl_preview` is translucent: the landing spot of
  the action being chosen.
- Shields: `shield_badge` (12x13, draw the count in white `font` centered at `x+6, y+2`),
  `shield_badge_broken` while Broken, small pips `shield_full | shield_empty | shield_broken` (8x8).
- Weakness row: `weak_frame` (14x14) with the 12x12 icon at `+1,+1`; `weak_frame_hit` flashes gold when a
  weakness is revealed or hit; `weak_frame_resist`; `weak_unknown` ("?"); `weak_null` (red slash overlay).
- `break_burst_0..3` (96x60, origin center, anim `break_burst` 15 fps, no loop) behind the `BREAK` word art.
- `reticle_0/1` (26x26, origin center), `target_arrow_0/1`, `turn_marker_0/1` (over the acting member),
  `elite_mark` (gold crown for elite names).
- Tiny 3x5 labels (gold, with shadow): `lbl_hp lbl_mp lbl_fury lbl_lv lbl_exp lbl_next lbl_atk lbl_def
  lbl_mag lbl_spd lbl_ready lbl_ko`.

### Field
- Emotes `emote_<name>_0/1` (16x16, origin `[4,15]` = balloon tail tip; place at the head top):
  exclaim (`!`), question (`?`), dots (`...`), heart, sweat, anger, music, zzz, idea. Anim `emote_<name>`
  has `intro: [emote_pop_0, emote_pop_1]` at 15 fps, then loops the two frames at 3 fps.
- Interaction prompts: `prompt_0..3` (bobbing arrow, anim `prompt`), `prompt_talk_0..2` (talk bubble with
  cycling dots), `prompt_check_0/1` ("!" examine bubble). Origins are the bottom tip.

### Touch skins and button glyphs
- `touch/dpad.png` (45x45) + `dpad_up|down|left|right.png`, `a.png` / `a_pressed.png`, `b.png` /
  `b_pressed.png` (26x26), `menu.png`, `run.png` (+ `_pressed`, 32x14). Pixel art at 1x; scale with
  `image-rendering: pixelated` (3x reads well on phones). Translucent dark glass with a light rim and an ink
  outline, so they read on bright and dark scenes. Same pieces are in `ui.json` as `touch_*`.
- Inline prompt glyphs, 11 px tall to sit in a text line: `btn_key_z|x|c|enter|esc|shift|q|e`,
  `btn_pad_a|b|x|y|lb|rb`, `btn_tap_a|b`. `ui.json` `buttonGlyphs[device][action]` maps actions to glyphs.

### Loot
- `beam_<rarity>_0..3` (15x64, origin bottom center, anim `beam_<rarity>` 8 fps) and
  `sparkle_<rarity>_0..3` (7x7, origin center), rarity = common | magic | rare | legendary | set.

## logo.json

`frames: logo, subtitle, sparkle_0..4`. Title layout: logo centered near the top, subtitle centered 3 px
below it. Spawn a sparkle (anim `sparkle`, 15 fps, one shot) every ~1.5 s at a random opaque pixel on the
upper half of the logo.
